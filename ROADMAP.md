
# Harmony - Roadmap

Harmony is an open project.
Help us bring it to life by requesting features
and reporting bugs.

## Planned Releases

### v0.3.0 - Smart entry (Todoist style) and search

**Timeline** : June 2026 
- [ ] Fast natural language processing (NLP) capture
    - Keyboard shortcut to open a quick entry plane anywhere in Obsidian.
    - Smart Analytics: Automatically extract dates (for example, "Friday," "tomorrow at 2:00 PM"), priorities and tags from the plain text.
    - Automatically add the scanned task to a default "Inbox.md" file or the currently active note.

- [ ] **Advanced search and filtering**
    - Filter your job engine dynamically by tags, priority, due date or status.
    - Search the text content of all indexed tasks.
    - Save custom search queries to create custom lists.

- [ ] **Mobile phones version**
    - Adapt the 3 existing modules (Todo, Kanban, Calendar) for mobile windows and touch controls.

### v0.4.0 - Task & Note Linking

**Timeline:** August 2026

- [ ] **Link Tasks to Notes**
    - Create custom links in notes to tasks (e.g., `[[Task: My Task]]`)
    - Click link to open Dashboard/Kanban/Todo with task highlighted
    - Display task details inline in notes
- [ ] **Backlinks from Tasks**
    - Tasks can link back to related notes
    - See all notes connected to a task
- [ ] **Productivity Statistics Dashboard**
    - Statistics dashboard (completed this week, streaks, etc.)
    - Keyboard shortcuts customization
    - Performance optimization for large task lists

### v0.5.0 - Future Ideas

**Timeline:** After September 2026

- [ ] **Productivity Extensions**
    - Pomodoro timer integration: Sync focused work sessions directly mapped to the active task.
    - Habit tracker module: Keep track of recurring daily/weekly routine goals via specific checkboxes.

- [ ] **Workflow & Integration**
    - Quick capture floating button: A rapid-access overlay or mobile-friendly floating button to add tasks in a single tap.
    - Export tasks (CSV, JSON): Backup or move task data easily for external data analysis.
    - External Task Manager integrations: Bridge Harmony to traditional tools and external calendars (Google Calendar, Apple Calendar, Microsoft Calendar).
